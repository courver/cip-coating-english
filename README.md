# 歧海循光涂装英语 · CIP Coating English

A single-page study game for **AMPP CIP Level 1 & 2** and marine coating English.

**Play:** https://courver.github.io/cip-coating-english/ (works on phone browsers; add it to your home screen)

- 21 step-by-step lessons: terms → key points → practice → speaking → checkpoint
- 90-question bank by CIP module, timed mock exams with per-module scores
- 459-term shipyard / coating glossary (中文 ↔ English)
- Speaking practice with the browser's own speech recognition and text-to-speech
- A text adventure that follows *Punishing: Gray Raven* Chapter 42 "Steering by Light"

Progress is stored only in your browser (localStorage).

Notes: the inspection content is a study aid compiled from AMPP CIP topics, SSPC, ISO 8501/8502, ASTM and IMO PSPC — always check against the current AMPP course book. Story excerpts from *Punishing: Gray Raven* belong to Kuro Games and are quoted for non-commercial study use; this is an unofficial fan project.
